# Unicorn Rocket Math

Step-by-step 4th grade practice with Comet the unicorn and Bolt the robot, aligned to the North Carolina Standard Course of Study.

- **Math Galaxy:** Homework Helper (type in any +, −, ×, ÷ problem), Fact Fuel-Up (single-digit facts with Streak Builder, Three Strikes, and optional timed modes), place value, multi-digit operations (area model, partial products, lattice; long division, partial quotients, area model), word problems, fractions, decimals, measurement, data, angles, and geometry.
- **Word Workshop:** stories, nonfiction, and a chapter book with "Prove it!" evidence questions, a Listening Lab, word parts, context clues, figurative language, spelling, capitalization, commas, grammar, print handwriting tracing, and a Paragraph Builder.
- **Hangar:** Robot Studio and galaxy map. Stars unlock new choices and are never spent.
- **For grown-ups:** settings, how it works, and a standards coverage table.

On phones, double-tap zoom is off, the Back button returns to Mission Control, the screen stays awake during missions, and it can be added to the home screen as a full-screen app. Multi-digit addition everywhere (outside Fact Fuel-Up) is worked in place-value columns.

It's a static site with no build step: open `index.html`, or publish with GitHub Pages (main branch, root folder). Progress is saved in the browser on each device.
